# Domain Monitor — Design Preview Bundle

This bundle contains standalone static HTML preview cards for two WordPress admin surfaces rendered by the plugin: the dashboard widget (`src/Admin/DashboardWidget.php`) and the settings page (`src/Admin/SettingsPage.php` + `src/Settings/PluginSettings.php`). Each card is self-contained, links a shared `_wp-admin.css` stylesheet that emulates core wp-admin styling (system fonts, `#f0f0f1` page background, `.postbox`/`.widefat`/`.form-table` primitives, and the canonical WP status colors), and renders inside a fixed-width stage sized to match the real context (400 px for the dashboard widget column, 800 px for the settings page). "Current" cards faithfully reproduce what the PHP renderers output today; "Proposed" cards demonstrate targeted UX improvements — better information hierarchy, urgency-coloured expiry countdowns, alert badges, grouped settings sections, inline empty states, and per-domain card layouts — all strictly within the WP admin visual language with no custom branding.
